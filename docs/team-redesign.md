# Team / Boss 重構設計

從「自動接案 + 動態指派」轉成「玩家自選產業 + 預設 team 對應」。重構規模大，先對齊資料模型 / UI / 經濟，再動工。

## 核心循環

1. 公司預設只開放 1 個產業（隨機送的第一隻狗的產業）。
2. 該產業 inbox 會持續來案件 → 該 team 自動上工。
3. 玩家每日：抽卡（看運氣強化 / 補新產業狗）、調整 team 編成、開關 team。
4. 解鎖更多產業 → 開新 team → 並行接更多案。
5. 案件完成 = 收入；員工日薪 + 設施費 = 支出。team 全關只剩設施費。

## 產業 / Team

4 大產業：`tech` / `design` / `marketing` / `service`。

每個產業對應一個 team：

```ts
type Team = {
  industry: ProjectCategory;     // 4 種其一
  open: boolean;                 // 是否開放接案
  memberIds: string[];           // 1-3 隻
  acceptedProjectId: string | null;  // 該 team 一次只接 1 個案
};

state.teams: Record<ProjectCategory, Team>;
```

### Team 開關規則

- **解鎖條件**：必須擁有 ≥ 1 隻該產業的狗才能開該 team。
- **未解鎖**：toggle 灰掉，提示「需要至少 1 隻 N 產業的狗」。
- **已解鎖、可開**：玩家可隨時切 open/close。
- **open 才會收到該產業的案件**；同時間只能有 1 個 active 案。
- **全部 close**：inbox 空、所有員工待命，**只付設施費**（薪資全免）。

### 隊伍編成

- 每 team 最多 4 隻狗，至少 1 隻；玩家在 team 編輯 UI 任意調動。
- 一隻狗可在多個 team（給人手不足時靈活運用），但一次只能參與一個進行中的案（active 案佔住）。
- 化學反應 / 對口加成沿用現有公式，玩家自己組合。

## 招募 / 抽卡

抽 1 隻狗的成本固定（例如 $200）；初期窮就慢慢攢、後期穩定就常抽。

**抽卡池**：先全隨機（4 產業均勻分布），16 種職業內 uniform。日後可加「鎖定池」（消耗特殊資源指定產業池）。

**抽出新狗**：
- 新產業狗 → 該 team 解鎖（可開啟）。
- 已有產業狗 → 自動進入該 team 的待命池（玩家可手動編入）。

**重複職業**：仍是新個體（不同名字 / stats），不會合成升階（強化系統見下）。

## 員工強化（替代現有升階）

刪掉 D→C→B→A→S 升階。改成「強化」系統：

```ts
type Dog = {
  // 移除 grade 自動晉升
  level: number;          // 1 ~ 10，玩家用強化材料升
  stats: { speed, quality, teamwork, charisma };  // 隨 level 提升
  learnedTraits: string[];  // 仍保留特性，但只能透過強化解鎖
};
```

**強化貨幣 = 金錢**：每升 1 級花費 $X（隨 level 遞增），不另設材料系統。

**強化效果**：
- Lv1 → Lv10：每級 stats +0.5 ~ 1（總計 +5 ~ 10）
- 特定 level 解鎖特性選項（Lv 3 / 6 / 9 各一次）

**升級成本範例**（暫定）：
- Lv1→2：$80
- Lv2→3：$120
- Lv3→4：$200
- ...每級 ×1.5，Lv9→10 約 $2000

## 案件生成 / 接案

```ts
state.clients: Project[]   // 所有 inbox 案件
```

- 每日 fillInbox：對「open team」對應產業，補到該產業 inbox 有 N 個案件（例如 3 個）。
- 全 close → 不補 inbox。
- 玩家不直接「接」案，team 自動接：當該 team 沒在做案、且 inbox 有對應產業案件 → 自動接最前面那個。
- 一次最多 4 個 active 案（每產業 1）。

**移除的機制**：
- 拒絕 / 重整收件匣（reroll）
- 案件期限（已移除）
- 中途事件（已移除）
- 跨產業動態指派（用 fixed team 取代）

**保留**：
- 案件完成獎勵（reward + 信譽 + 經驗 + 強化材料）
- 放棄案件（手動，付違約金）
- 「最快 2 天」floor

## 經濟平衡

| 項目 | 機制 |
|------|------|
| 抽卡 | 固定 $100 / 抽 |
| 強化升級 | $80 起，每級 ×1.5 至 Lv10 |
| 案件 reward | 沿用 tier 系統 |
| 員工日薪 | 沿用 expectedSalary |
| 設施費 | 沿用 OFFICE_DAILY_EXPENSE |
| 全 team 關 | 員工日薪 0，僅付設施費 |
| 強化材料 | 案件完成隨機 + 閒置 team 每日少量 |

「全關只付設施費」是安全閥 —— 玩家被卡狗時可暫停接案、靠剩餘現金等下次抽卡，不會被連續日薪燒爆。

## UI 變動

### 主要面板

- **角色介面（grid）**：所有員工以 6×N 格子顯示，標示產業色、level、所屬 team。點擊 → 強化 / 編入 team / 查看狀態。
- **Team 面板**：4 個產業卡，顯示 team 編成、open/close switch、目前案件、預估剩天。
- **抽卡入口**：取代現有「招募中心」，按鈕「抽卡 $200」。
- **案件清單**：依 team / 產業分區，顯示進行中。

### 移除 / 簡化

- 候選人面試卡（履歷、耐心）→ 全刪
- 商店中的設備購買保留（buff 仍有用）；擴建已分到營建抽屜
- inbox 重整、拒絕案件 → 全刪
- 自動接案策略代碼（pickAutoAssign / applyAutoAccept / wait-vs-now）→ 簡化或刪

## 移植策略

不向後相容：舊存檔載入後跳「重新開始」提示，新存檔走新格式。簡化資料遷移成本。

## 範圍 / 階段

- **Phase 1**：資料模型重構（GameState、Team、Dog 簡化）+ 抽卡 + grid UI 骨架
- **Phase 2**：team 開關、案件生成依 open team、自動接案
- **Phase 3**：強化材料 / level / 特性解鎖
- **Phase 4**：UI 拋光、平衡參數、教學引導

每個 phase 約 1-2 個工作日的量，逐步來，每 phase 結束 build 可玩。

## 已定參數

1. **抽卡 $100 / 抽**（先試 $100，後期可調）
2. **Team 容量 1-4**
3. **強化材料 = 金錢**（不另設材料系統）
4. **Level 上限 10**
