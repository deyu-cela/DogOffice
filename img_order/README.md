# 排行榜（Leaderboard）— 圖片需求工單

> 設計：紙感拼貼風格（手帳 / scrapbook）
> 主色：粉紅 #df6374、金 #ffb838、米白 #fffaf2
> 風格參考：遊戲整體主視覺（柔和粉彩、手繪線條、紙張質感）

## 共通規範
- **格式**：PNG，**透明背景**
- **解析度**：以下尺寸是顯示尺寸 @1x，請出 **@2x（2 倍大）** 以對應 Retina
- **風格**：手繪線條（不要太寫實）、柔和陰影、不要強烈漸層、不要 3D
- **配色**：以遊戲現有色票為主，不要鮮豔螢光色
- **檔名**：全小寫、kebab-case、放在 `public/assets/leaderboard/`
