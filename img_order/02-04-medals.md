# 02–04 · medal-gold / silver / bronze.png

## 用途
排行榜 podium 區，第 1 / 2 / 3 名 podium 卡片頂部的獎牌圖示。

## 規格
- 顯示尺寸：36 × 36 px（第 1 名顯示 42×42）
- 出圖尺寸：**84 × 84 px @2x**
- 格式：PNG，透明背景
- 檔案路徑：
  - `public/assets/leaderboard/medal-gold.png`
  - `public/assets/leaderboard/medal-silver.png`
  - `public/assets/leaderboard/medal-bronze.png`

## 視覺方向
紙感手繪風的圓盤獎牌 + 緞帶。三顆要**形狀完全一致**，只差顏色：
- 圓形獎牌正面有星星 / 數字 1·2·3 浮雕（任選一種統一）
- 上方接一條短緞帶（V 字型剪角，類似頒獎典禮）
- 緞帶顏色：金=粉紅 (#ef6f8f)、銀=灰藍 (#a8b0c8)、銅=橘棕 (#c88566)
- 獎牌主色：
  - **金**：金色漸層 `#ffd86b → #ffb838`，深金邊
  - **銀**：銀色漸層 `#e8e8ee → #b8b8c8`，深灰邊
  - **銅**：銅色漸層 `#ffcfa3 → #d18b5a`，深棕邊

## 不要
- 不要 3D
- 不要寫實金屬反光（柔和高光可）
- 不要刻字（除非是「1 / 2 / 3」浮雕數字）

Each 84x84 px, identical shapes, only color differs.
